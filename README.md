# 상표 크롤링 (Trademark Crawling)

이 프로젝트는 상표 정보를 크롤링하는 파이썬 스크립트를 포함하고 있습니다. 
수집하는 정보의 깊이에 따라 두 개의 브랜치(Branch)로 나누어 코드를 관리하고 있습니다.

## 🌿 브랜치별 기능 안내

### 1. `basic_info` 브랜치
상표의 **기본 정보**를 수집하는 코드가 포함되어 있습니다.
* **수집 항목:** 상표명, 행정상태, 등록공고번호, 상품분류, 출원인, 최종권리자, 상표URL

### 2. `detailed_info` 브랜치
기본 정보에 더해 **상세 정보**까지 수집하는 코드가 포함되어 있습니다.
* **수집 항목:** `basic_info`의 모든 항목 + **최종권리자에 대한 상세 정보**
